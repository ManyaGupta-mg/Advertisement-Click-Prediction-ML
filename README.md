# Advertisement Click Prediction Using Logistic Regression

## About Project
This is a machine learning practice project to predict whether a customer will click an online advertisement based on demographic and browsing behavior data.

## Objective
Build a binary classification model using Logistic Regression to predict ad click probability.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset Features
- Daily Time Spent on Site
- Age
- Area Income
- Daily Internet Usage
- Gender
- Country
- Clicked on Ad (Target)

## Data Processing
- Checked and cleaned the dataset
- Converted the Data types of Column Male and Timestamp
- Split data into training and testing sets
- Trained a Logistic Regression model

## Model
- Logistic Regression

## Model Performance
- Accuracy: 95%
- Precision: 96%
- Recall: 95%
- F1-score: 96%

## Conclusion
The model successfully predicts customer ad-click behavior and identifies patterns related to user engagement.
